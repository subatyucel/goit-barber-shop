# BarberShop

Welcome to the BarberShop website repository. This project is a fictional barber shop website created using HTML, CSS, Git, and a bit of JavaScript.

## Project Overview

BarberShop is a modern and responsive website for a barber shop. It showcases the services offered, introduces the barbers, and provides contact information for booking services.

## Features

- **Responsive Design**: The website is fully responsive, catering to desktop, tablet, and mobile devices.
- **Service Listings**: Detailed descriptions of services and their prices.
- **Barber Profiles**: Information about the barbers available at the shop.
- **Contact Form**: A form for users to book services directly from the website.
- **Social Media Links**: Direct links to the shop's Instagram and YouTube pages.

## Technologies Used

- **HTML**: Structure of the website.
- **CSS**: Styling and layout of the website.
- **JavaScript**: Interactive elements and functionality.
- **Git**: Version control.
